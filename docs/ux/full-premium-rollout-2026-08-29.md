## Shared contract applied

- Shell geometry: every route root inherits `neo-shell-frame` / `neo-shell-main` /
  `neo-content-shell` / `neo-shell-bleed`; `.neo-shell-bleed > *` now pins
  `min-width: 0` so no page can force page-level horizontal scrolling.
- States: `LoadingState`, `EmptyState`, `ErrorState`, `NotAuthorisedState`,
  `NotConfiguredState` from `@/components/common/StateSystem` replace ad-hoc
  spinners, empty paragraphs and raw provider error text.
- Toolbars: filter controls use responsive `w-full sm:w-*` widths instead of
  fixed pixel widths.
- Money is rendered through `MoneyValue`; density and spacing come from the
  shared tokens rather than per-page values.
